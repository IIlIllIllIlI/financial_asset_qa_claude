# EBITDA：息税折旧摊销前利润

## 定义

EBITDA 是 Earnings Before Interest, Taxes, Depreciation, and Amortization 的缩写，中文称为**息税折旧摊销前利润**。它用于评估公司核心业务的经营盈利能力，剔除了融资决策、税务环境和会计政策等非经营性因素的影响。

## EBITDA 的用途

EBITDA 排除以下费用，从而更清晰地反映公司主营业务的真实盈利能力：

- **利息（Interest）**：取决于公司的融资结构（债务与股权的比例），与业务运营本身无关。
- **税费（Taxes）**：取决于公司注册地和税务筹划，与经营水平无关。
- **折旧（Depreciation）**：非现金支出，基于历史资产投资和不同的折旧会计方法。
- **摊销（Amortization）**：与无形资产相关的非现金支出，同样是会计选择的结果。

简而言之，EBITDA 回答了一个核心问题：**公司的主营业务到底赚了多少钱？**

## EBITDA 的两种计算公式

**公式一：从净利润出发（自下而上）**

```
EBITDA = 净利润 + 利息费用 + 税费 + 折旧费用 + 摊销费用
```

**公式二：从营业利润出发（自上而下）**

```
EBITDA = 营业利润（EBIT） + 折旧费用 + 摊销费用
```

两种公式计算结果是相同的。

## 计算示例

某公司报告如下数据：
- 净利润：50,000 元
- 利息费用：10,000 元
- 税费：8,000 元
- 折旧费用：12,000 元
- 摊销费用：5,000 元

```
EBITDA = 50,000 + 10,000 + 8,000 + 12,000 + 5,000 = 85,000 元
```

## EBITDA 相关指标

- **EBIT**：息税前利润，即营业利润。EBIT = EBITDA - 折旧 - 摊销。EBIT 反映的是包含折旧和摊销影响的经营利润。
- **EBT**：税前利润。EBT = EBIT - 利息费用。
- **净利润（Net Income）**：扣除所有费用后的最终盈利，即"底线利润"。
- **EBITDA 利润率**：EBITDA ÷ 营业收入，衡量公司主营业务效率，比例越高说明经营效率越好。
- **净债务/EBITDA 比率**：衡量公司用经营利润偿还债务的能力，常用于信用评级分析。

## EBITDA 的常见应用场景

1. **企业估值**：用于计算 EV/EBITDA 倍数，在可比公司分析中非常常用。EV（企业价值）= 市值 + 债务 - 现金。
2. **信用分析**：银行和债权人用 EBITDA 评估企业偿债能力。通常认为 EBITDA 应至少为利息费用的 2 倍以上。
3. **财务建模**：在 DCF 模型中，EBITDA 是计算企业自由现金流的重要起点。
4. **业绩对标**：剔除资本结构和税收差异后，方便跨公司、跨行业比较经营效率。

## EBITDA 的局限性

- **忽视真实成本**：利息和税费是公司必须支付的真实费用，EBITDA 排除它们可能会美化实际情况。
- **不包含资本支出（CapEx）**：公司维持运营所需的设备更新、厂房扩建等资本支出未在 EBITDA 中体现。对于重资产行业，这是一个严重的缺陷。
- **可能夸大盈利能力**：一家公司可以有正的 EBITDA 同时有净亏损（因为利息和折旧远高于经营利润）。
- **非 GAAP 指标**：EBITDA 不是公认会计准则（GAAP）定义的指标，不同公司可能采用不同的计算方式，导致可比性下降。
- **对重资产企业有误导**：制造业、航空业等折旧成本很高的行业，在 EBITDA 口径下看起来可能比实际更赚钱。判断这类企业时务必同时关注折旧和资本支出。
